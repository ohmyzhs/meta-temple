# 청연산사 (清蓮山寺) — 무설치 웹 3D 메타버스 온라인 사찰

> **"말없이 같이 머물며 산사의 바람·풍경 소리를 듣고, 절·연등·사경·차담으로 마음을 비우는 웹 3D 디지털 안식처"**

본 프로젝트는 **무설치·무로그인 웹 접근성(Zero-Friction Web Entry)**과 **실사에 가까운 3D 산사 분위기·입체 공간 ASMR**, 그리고 **실제 전통 사찰의 다채로운 신행 활동(108배, 염주 굴리기, 헌향, 소원 연등, 기와 불사, 탑돌이, 돌탑 쌓기, 번뇌 소각장, 반야심경 사경, AI 스님 차담)**을 결합한 웹 3D 온라인 사찰 프로토타입 및 설계 패키지입니다.

다른 IDE나 AI 코딩 도구(Cursor, Claude Code, Windsurf 등)에서 즉시 이어받아 작업할 수 있도록 상세 기획·설계·기술 스펙 문서를 `docs/` 디렉터리에 함께 수록했습니다.

## 3. 프로토타입 주요 구현 기능

- **심리스 4대 가람 구역 (Zone 1 ~ Zone 4)**:
  - **Zone 1 (일주문 & 전나무 숲길)**: 전통 일주문, 전나무 군락, 계곡 돌다리(석교), **소원 돌탑 쌓기**
  - **Zone 2 (대웅전 앞마당 & 삼층석탑)**: 천년 삼층석탑(**탑돌이**), 하늘을 수놓는 **소원 연등 달기 & 열람**, **기와 불사 각인**, **번뇌 소각 화로**(적은 고민을 불꽃·연기로 태워 완전 소멸), **범종각 타종 체험**
  - **Zone 3 (대웅전 법당 내부)**: 금동 삼존불과 후불탱화, **헌향·헌촉(향 연기·촛불 점등)**, 32개 수행 좌복 착석, **108배 수행(호흡 가이드 & 카운터)**, **염주 굴리기**, **디지털 사경(반야심경·법구경 필사)**
  - **Zone 4 (후원 다실 & 연못 정자)**: 대나무 숲과 연꽃 연못, 툇마루 다실(심검당), **AI 선사(스님) 1:1 비공개 차담** 및 **오늘의 죽비(경전 카드) 뽑기**
- **실시간 시간대·날씨 조명 및 파티클 엔진**:
  - `실시간 동기화` / `새벽 안개(05:00)` / `한낮 햇살(13:00)` / `저녁 노을(18:00)` / `산사의 밤(22:00)`
  - `맑음(반딧불·솔잎)` / `산사 봄비(빗줄기·젖은 마당 반사광)` / `겨울 설경(눈송이 파티클)`
- **아바타 3종 & 침묵의 동석(Silent Co-presence)**:
  - `목각·백자 동자승`, `삿갓 수묵 행자`, `연꽃 등불 정령` 실시간 외형 전환 및 공덕 달성 시 **손목 단주·손연등** 장착
  - 단축키 `1~6` 또는 하단 액션 바로 **합장 반배, 큰절, 가부좌·염주, 헌향, 탑돌이, 차 마시기** 수행 및 주변 동석 참배객들의 비언어 답례 합장
- **Web Audio API 입체 ASMR 사운드 믹서**:
  - 외부 음원 파일 의존 없이 브라우저 네이티브 Web Audio API 합성으로 구현된 **자연음(솔바람·계곡물·산새·빗소리)**, **사찰음(처마 풍경·독송 드론·청동 범종)**, **효과음(목탁·죽비·염주·불꽃)** 3채널 독립 믹서 및 구역별 자동 공간 감쇠
