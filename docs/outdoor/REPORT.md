# 바깥 실사 보고 (?world=real, 2026-11-06)

청연산사 바깥(숲길·순환 산책로·산세)을 폴리곤을 늘리지 않고 **생성 사진·사진 질감**으로 실사에 가깝게 바꿨다.
스펙 `docs/superpowers/specs/2026-11-05-launch-upgrade-design.md`, 아트 바이블 `docs/art/ART-BIBLE.md`(lucid-moser 브랜치).

## 사용자 방향 (작업 중 받은 말)
> 산책중 자리에 앉아서 고정된 위치에서 주변을 둘러볼때는 이미지화를 많이 해서 경치를 좋게 만들고,
> 그냥 단순히 걸을땐 더 자연스러운 세계를 표현하는게 좋을것 같다.

- **앉았을 때 (쉼터 11곳)**: 그 쉼터 쪽 경치를 생성 사진 한 장(110°, 낮·해질녘·밤)으로 원통에 띄운다. 앉은 자리에서 0.8초 머물면 받아서 서서히 나타나고, 일어서면 사라진다.
  사진의 지평선은 그 방향 앞산 스카이라인 위로 올려 먼 산줄기가 3D 언덕·나무 위로 보이게 하고, 지평선 아래(가까운 숲)는 3D 세계에 맡긴다.
  경치 4종을 쉼터 성격에 맞춰 나눴다 — 산사 내려다보기(전망 바위·능선 돗자리), 서쪽 산줄기(대숲 벤치), 숲 사이 먼 산(그루터기·약수터·데크), 계곡 따라(다리·개울).
- **걸을 때**: 실제 지형·나무·소품 위에 사진 질감만. 시차가 있는 곳에는 그림을 세우지 않는다.

## 범위 4가지
| | 무엇을 | 어디서 |
|---|---|---|
| 1 원경 | 평면색 능선 띠 3겹 → 생성 사진 띠 3겹 (가까운·중간·먼 능선, 낮·해질녘·밤을 `world.hour`·`env.night` 로 섞음). 프레임 3장 + 좌우 뒤집은 3장을 360° 로 이어 붙임 | `outdoor.js` RIDGE_LAYERS, `build.py ridges` |
| 1+ 먼 산자락 | 바깥 지형(3m 격자)이 실제로 보이는 "먼 산"이라, 30→75m 에서 숲 바닥을 위에서 본 숲 지붕 사진(생성, 이음새 없음)으로 | `GROUND_LAYERS[6]`, `CANOPY` |
| 2 지면 | 정점색 대신 사진 질감 7층(숲 바닥·낙엽·흙길·마사토·잔디·냇돌·숲 지붕)을 `groundColor` 와 같은 마스크로 섞음 (KTX2 배열 텍스처 하나 = 샘플러 하나) | `groundSplat`, `groundMaterial` |
| 3 나무 | 전나무·소나무·단풍·대나무 잎을 생성 잎 아틀라스 카드로, 줄기는 나무껍질 사진. 산책로·마당·쉼터에서 24m(저사양 18m) 넘게 떨어진 나무는 원경 나무 그림 카드(원기둥 빌보드, 그리기 1회). 인스턴스 위치·개수·충돌·수관 목록은 그대로 | `firCards` 등, `_impostors` |
| 4 소품 | 데크·나무다리·징검다리·쉼터 6종 + 길가 바위에 판재·화강암·이끼 돌 사진 PBR. 상자 투영 UV(미터 단위, 판재 한 장에 판 하나) | `prepareProps`, `boxUV` |

## 플래그
- 2026-11-06 사용자 결정으로 **기본값 켬** (`templeScene.js` 의 `REAL_WORLD` 기본값 true, 석탑·법당 실사와 같은 스위치). `?world=classic` 이면 예전 절차적 세계 — `outdoor.js`·에셋을 받지 않는다. 롤백은 그 기본값 한 줄.
- 기존 파일 손댄 곳: `templeScene.js` 2줄(동적 import·update), `vegetation.js` 반환값, `trailProps.js`·`terrain.js` 의 userData 표시 — 렌더에 영향 없음.
- 같은 화면 비교 (앱 루프 멈춤, 고정 씨앗, 같은 t): 플래그 끔 vs 9a27c0a 의 차이가 9a27c0a 끼리 두 번 찍은 차이(방문객·반딧불)와 같은 크기, 숲길 6장은 픽셀까지 같다. 그리기 호출·삼각형은 아래 표.

## 받는 용량 (KTX2, 폰은 _lo)
| 묶음 | 폰 | 데스크톱 | 언제 |

| 첫 입장 (지면 2.42 + 나무껍질 0.59 + 소품 1.31 + 잎·원경 나무 + 지금 시각 원경 띠 3장) | 5.36MB | 6.94MB | 입장 직후 뒤에서 |
| 다른 시각 원경 띠 (해질녘·밤) | 1.22MB | 2.21MB | 그 시각이 다가올 때 |

해질녘·밤은 낮 그림을 편집해 능선 모양을 맞췄다. 사진 질감은 Poly Haven CC0 13종.

## 한계·남은 일
- 성능 수치는 M4 Pro GPU(헤드리스 Chrome, ANGLE Metal)라 폰 실기와 다르다. 폰 실기 측정이 필요하다.
- 순환로가 숲 전체를 감싸서 원경 나무 카드로 바뀌는 나무는 적다 (아래 수치). 나무 수를 줄이지 않는 조건이라 그대로 둠.
- 원경 띠는 3장을 뒤집어 6구간으로 썼다. 전망 바위처럼 넓게 보이는 곳에서 반복이 보이면 프레임을 더 만든다.
- 바깥 지형 언덕 모양 자체(매끈한 원뿔)는 그대로 — 모양까지 바꾸려면 지형 높이 함수(`layout.js`)를 손대야 한다 (지도 세션 영역).
