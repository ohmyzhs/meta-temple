## 클립 대응

| 행동 상태 (동기화 이름) | 클립 | 비고 |
|---|---|---|
| idle (숲길 / 경내) | `idle` / `idle_chasu` | 경내(마당·법당·다실)에서는 차수로 선다. 받는 쪽이 도반 위치로 고른다. |
| 걷기 (숲길 / 경내) | `walk` / `walk_chasu` | 모든 곳 1.1m/s, 초당 3걸음으로 구웠다. 뛰지 않는다. |
| circumambulate | `walk_gassho` · 서 있으면 `gassho` | 합장하고 시계 방향. |
| lookUp (연등 바라보는 참배객) | `look_up` | 차수하고 고개를 든다. |
| bow_half | `bow_half` (2.47s) | 합장 → 숙임 → 합장 → 손 내림. 눈을 감는다. |
| prostrate | `prostrate` (7.6s) | 위 큰절 순서, 가사 수한 스님 방식. 이마는 3.6s. 앉아 있었으면 `stand_up` 1.5s 를 먼저. 자동 108배는 8초에 한 번. 도복 스치는 소리 6번. |
| sit | `sit` | 반가부좌·법계정인, 눈 감음. 서 있다 앉으면 `sit_down` 을 먼저. |
| meditate | `meditate` | 반가부좌, 오른손 엄지로 염주를 1.1초에 한 알 (손에 염주). |
| tea | `tea` (7초 고리) | 오른손바닥에 잔을 얹고 왼손으로 받쳐 들어 향을 맡고 마신다. |
| incense | `incense` (3.4s) | 오른손으로 향을 잡고 왼손으로 받쳐 들어, 이마 쪽으로 올렸다가 꽂고 합장. 다실 선사(앉은 채)는 `serve_tea` — 두 손으로 찻잔을 건넨다. |
| offer_stone (새) | `offer_stone` (3.0s) | 돌탑에 조약돌을 얹을 때: 쪼그려 두 손으로 받쳐 놓고 일어나 합장. |
| write_tile (새) | `write_tile` (3.2s) | 기와를 올릴 때: 왼손에 기와, 오른손 붓으로 세 획, 받들어 올리고 합장. |
| hang_lantern (새) | `hang_lantern` (3.0s) | 연등을 띄울 때: 두 손으로 머리 위로 올려 보내고 올려다본 뒤 합장. |
| 사경 (보낼 때는 sit) | `sutra` (4초 고리) | 사경 서안 앞에 앉아 몸을 숙이고 왼손으로 종이를 누르고 붓으로 쓴다. 받는 쪽이 서안 자리(0.35m 안)에 앉은 도반을 사경으로 보인다 — 옛 클라이언트에게는 예전처럼 앉아 보인다. |

서서 하는 새 상태 세 가지(offer_stone·write_tile·hang_lantern)는 `server/server.js` 의 ACTIONS 에도 넣었다. **서버를 배포해야 다른 도반에게 보인다.**
그 전에는 서버가 idle 로 바꿔 전하고, 옛 클라이언트는 모르는 상태를 선 자세로 둔다 — 서서 하는 몸짓이라 어느 쪽도 깨지지 않는다.

## 치비라서 바꾼 것

- 머리 폭(0.6m)이 팔 벌린 폭보다 넓어, 큰절에서 두 손은 머리 양옆이 아니라 머리 조금 뒤 양옆(±0.21m)을 짚는다. 이마는 두 손보다 앞에서 바닥에 닿는다.
- 합장 높이: 실제로는 가슴 앞이지만, 짧은 팔로 둥근 배를 지나야 해서 손목이 가슴 아래(0.565m)에 오고 손끝이 턱 밑을 향한다.
- 다리 길이 0.31m: 걸음이 짧아 종종걸음(3.75걸음/s), 빠르게 갈 때는 콩콩 뛴다.
